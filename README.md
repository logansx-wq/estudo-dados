# Laboratório de Estudos: Dados e BI

Repositório central de estudos e práticas. 

Aqui, documento o meu aprendizado diário, armazeno scripts de fixação e construo mini-projetos focados em Análise de Dados, Engenharia de Dados e Business Intelligence. O objetivo é consolidar conceitos teóricos através da resolução de problemas práticos.

## Estrutura

Para facilitar a navegação, os estudos estão organizados em pastas independentes por projeto ou tecnologia. Atualmente, o repositório contém:

* **[analise-de-dados-pandas](./analise-de-dados-pandas):** Estudo focado na ingestão, limpeza e enriquecimento de bases brutas de cadastros, metas e vendas utilizando Python e a biblioteca Pandas.
* **[pipeline_medalhao_consumidor](./pipeline_medalhao_consumidor):** Estudo em litígios de consumidores separado por camadas (bronze, silver, gold)
* **[jira-sla-analytics-pipeline](./jira-sla-analytics-pipeline):** Pipeline de dados ponta a ponta que extrai chamados da API REST do Jira Cloud com Python, armazena em nuvem no PostgreSQL (Supabase) via Arquitetura Medalhão e calcula métricas líquidas de SLA e gargalos operacionais com SQL avançado..
* *(Em breve: Novos diretórios cobrindo modelagem dimensional, consultas analíticas e visualização de dados).**

## Tecnologias e Ecossistema

As práticas documentadas neste repositório refletem minha trilha de aprimoramento técnico e englobam as seguintes ferramentas:

* **Python:** Tratamento de dados, automação e análise exploratória (Pandas, NumPy).
* **Bancos de Dados (SQL):** Modelagem relacional (Star Schema/Snowflake), views analíticas, agregações e subqueries estruturadas (PostgreSQL, SQL Server).
* **Business Intelligence (Power BI):** Linguagem DAX, transformações via Power Query (Linguagem M) e construção de relatórios executivos.
* **Arquitetura e Versionamento:** Lógica de processamento em camadas e versionamento de código com Git/GitHub.

## Como navegar

Cada subpasta deste repositório representa um ambiente isolado. Ao entrar em qualquer diretório de projeto, você encontrará o seu próprio `README.md` detalhando o contexto do estudo, os desafios técnicos enfrentados e as instruções para execução dos scripts.
